# SearchX

ממשק חיפוש בעברית שמציג תוצאות בתוך האתר. מנוע החיפוש מאחורי הקלעים הוא SearXNG, שמאגד תוצאות ממנועי חיפוש שונים.

## מבנה הפרויקט
- `site/index.html` — ממשק החיפוש.
- `docker-compose.yml` — מפעיל את האתר ואת מנוע החיפוש.
- `searxng/settings.yml` — מפעיל החזרת תוצאות JSON ומגדיר ממשק עברי.
- `nginx.conf` — מחבר בין ממשק האתר למנוע החיפוש.

## הפעלה מקומית
1. מתקינים Docker Desktop במחשב.
2. פותחים את `searxng/settings.yml` ומחליפים את `secret_key` במחרוזת אקראית ארוכה וייחודית.
3. ב-`docker-compose.yml` משנים את `SEARXNG_BASE_URL` ל-`http://localhost:8080/` לצורך בדיקה מקומית.
4. פותחים חלון Terminal בתיקיית הפרויקט ומריצים: `docker compose up -d`.
5. נכנסים בדפדפן לכתובת `http://localhost:8080`.

## פריסה באינטרנט
GitHub Pages לבדו אינו מספיק: הוא מארח קבצים סטטיים, אבל SearXNG צריך שרת פעיל. כדי להעלות את SearchX לאינטרנט צריך שרת/VPS שתומך ב-Docker, להגדיר בו HTTPS ודומיין, ולעדכן את `SEARXNG_BASE_URL` לכתובת הציבורית.

## מגבלות חשובות
- SearchX מציג תוצאות ממקורות שמנועי SearXNG המופעלים בשרת מצליחים לגשת אליהם. הוא אינו מבטיח שכל חיפוש יגיע דווקא ל-Google או שיכלול את כל האינטרנט.
- מנועי חיפוש חיצוניים עשויים לחסום, להגביל או לשנות את השירות שלהם; לכן איכות וכמות התוצאות עשויות להשתנות.
- אין לפרסם שרת פתוח בלי HTTPS, מפתח סודי חזק, עדכונים והגבלת שימוש מתאימה.
