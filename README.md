# SearchX

מנוע חיפוש בעברית עם ממשק RTL כהה. החיפוש הכללי נשלח דרך Cloudflare Worker ל-Google, והתוצאות מוצגות בתוך SearchX במקום להעביר את המשתמש לעמוד תוצאות של Google.

## מה כלול
- ממשק מותאם לנייד ולמחשב.
- חיפוש כללי דרך Google באמצעות שרת Cloudflare Worker.
- תוצאות חיפוש מוצגות בתוך SearchX.
- חיפוש תמונות וחדשות דרך מקורות פתוחים.
- היסטוריית חיפושים מקומית בדפדפן.
- אין צורך במפתח API או במנוי לשירות חיפוש.

## פריסה
הפרויקט מוגדר ל-Cloudflare Workers עם Static Assets:
- Worker: `src/index.js`
- ממשק: `site/index.html`
- הגדרות: `wrangler.toml`

לאחר דחיפת שינויים לענף `main`, Cloudflare Builds אמור לבנות ולפרוס את הגרסה החדשה אם חיבור GitHub לפרויקט עדיין פעיל.

כתובת Worker הצפויה: `https://searchx.m0556737829.workers.dev`

## איך החיפוש עובד
1. הדפדפן שולח את מילת החיפוש לנתיב `/api/search` של ה-Worker.
2. ה-Worker פונה לכתובת החיפוש הציבורית של Google ומנסה לחלץ את הכותרות, הקישורים וקטעי התיאור.
3. ה-Worker מחזיר JSON, ו-SearchX מציג את התוצאות בממשק שלו.

## מגבלות חשובות
- זהו חיבור ללא API מסחרי וללא תשלום לספק חיפוש, אבל הוא מסתמך על מבנה עמוד התוצאות הציבורי של Google.
- Google עשוי להציג CAPTCHA, להגביל תעבורה או לשנות את מבנה העמוד. במקרה כזה החיפוש עלול להיכשל זמנית עד לעדכון הקוד.
- אין הבטחה שכל תוצאה או כל תכונה של Google תהיה זמינה.
- Cloudflare Workers Free כפוף למכסות ולתנאי השימוש של Cloudflare.
- אין להשתמש בשרת כפרוקסי ציבורי פתוח לעומסים גדולים; מומלץ להוסיף הגבלת קצב ואימות לפני פתיחת השירות לקהל.
